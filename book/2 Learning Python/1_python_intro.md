# Introduction to Python

Python, a programming language released in 1991, has been designed with a primary objective of being easy to read and learn. Over the past few decades, it has become one of the world's most popular programming languages and is now widely used in science, engineering, and data analysis. Its extensive ecosystem of scientific libraries such as NumPy, Matplotlib, SciPy and Pandas is very well suited for biomechanical analyses, making it an accessible and flexible choice for both students and experienced researchers.

In this chapter, you will learn the main features of the Python programming language through examples and exercises focused on the biomechanical analysis of human movement.
