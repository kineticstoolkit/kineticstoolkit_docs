# Where to start

Depending on your background, you may want to start your journey at different points:

**I never programmed using Python.**

- Simply start at the beginning: [](2_getting_started_installing.md).


**I know Python, NumPy, and Matplotlib, but I'm new to biomechanical analysis.**

- Jump to [](../5%20Manipulating%20TimeSeries/1_ktk_intro.md).


**I already do biomechanical analysis, but under Matlab instead of Python.**

- You may want to start at the beginning to install a Python environment: [](2_getting_started_installing.md) 
- Then learn the Python syntax: [](../2%20Learning%20Python/1_python_intro.md);
- You may skip Matplotlib as this is practically identical to Matlab.
- However, be sure to go through NumPy as there are some fundamental differences between Matlab and NumPy: [](../4%20Manipulating%20Arrays/1_numpy_intro.md)
- Then, jump to [](../5%20Manipulating%20TimeSeries/1_ktk_intro.md).


**I already do biomechanical analysis under Python.**

- Start directly here: [](../5%20Manipulating%20TimeSeries/1_ktk_intro.md).
- You may also consult the {{ktk_api_reference}}.
